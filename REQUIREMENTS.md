# Requirement mapping

| Received requirement | Where to try it |
| --- | --- |
| Account/authentication, payment method, address | Sign in / Create account; My account |
| Local stores with name, location, hours, customer reviews | Shop stores; Change location; Customer reviews |
| Select a store and search its inventory | Store cards, inventory search, category filters |
| Product names, prices, availability | Product cards, Out of stock, inventory limits |
| Cart quantities, product prices, subtotal | Your cart, plus/minus controls |
| Flat fee and tax | Cart totals and checkout receipt |
| Secure checkout with account payment method | Secure checkout; clearly labeled test methods |
| Pickup time and designated pickup person | Checkout form |
| Order confirmation and order number tied to a store | My orders and in-app confirmation |
| Employee order status and ready-for-pickup update | Employee desk → Pickup orders |
| Employee updates store information/inventory | Employee desk → Store details / Inventory |
| Rating and comment from a customer with an order number | My orders → Leave a review; store customer reviews |
| Shared cart guests can add items but cannot check out | Share cart / Shared carts; server-side owner checks |
| Questions arising during vibe coding | QUESTIONS.md |
| Locally hosted app and run instructions | README.md; npm run setup and npm run dev |

All product data and payment methods are demonstrative. See README.md for integration boundaries.
